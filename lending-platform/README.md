# Lender — Πρωτότυπο χρηματοδότησης ελληνικών επιχειρήσεων

Responsive, ελληνόφωνο πρωτότυπο για χρηματοδότηση ελληνικών επιχειρήσεων (P2B). Τα ενδεικτικά αιτήματα και οι επενδυτικοί γύροι κινούνται στην περιοχή των €10.000–€50.000. Δεν πρόκειται για ενεργή χρηματοοικονομική υπηρεσία.

## Τοπική εκτέλεση

Εκκίνησε το τοπικό backend (απαιτείται Python 3, χωρίς πρόσθετα πακέτα):

```sh
python3 server.py
```

Έπειτα επισκέψου το `http://127.0.0.1:8001`. Η βάση SQLite δημιουργείται στο `.local-data/lender.sqlite3`, μέσα σε φάκελο με δικαιώματα πρόσβασης μόνο για τον λογαριασμό σου. Τα αιτήματα επιχειρήσεων, οι δοκιμαστικές συνεισφορές, οι προσφορές, οι συμμετοχές και οι αγγελίες διατηρούνται μετά την ανανέωση της σελίδας. Η υπηρεσία ακούει μόνο στη συσκευή σου και ελέγχει την προέλευση των αιτημάτων.

Το πρωτότυπο δεν έχει λογαριασμούς χρηστών: τα δεδομένα της τοπικής βάσης είναι κοινά μεταξύ καρτελών του ίδιου browser και της ίδιας συσκευής. Η επίσκεψη μέσω `python3 -m http.server` ή με άνοιγμα του HTML απευθείας δεν συνδέει το backend, οπότε οι αλλαγές δεν διατηρούνται.

Έλεγχοι backend:

```sh
python3 -m unittest discover -s tests
```

## Δημόσια προεπισκόπηση μέσω Render

Το αποθετήριο GitHub μπορεί να παραμείνει ιδιωτικό· δεν χρειάζεται να δημοσιεύσεις τον πηγαίο κώδικα. Το Render χρειάζεται πρόσβαση στο αποθετήριο για αυτόματες αναπτύξεις. Ο ιστότοπος προεπισκόπησης που θα δημιουργήσει το Render είναι δημόσιος και μπορείς να στείλεις τον σύνδεσμό του στους φίλους σου. Το υπάρχον `render.yaml` δημοσιεύει μόνο τη στατική προεπισκόπηση, όχι τη βάση ή το backend.

1. Δημιούργησε αποθετήριο GitHub, κατά προτίμηση ιδιωτικό, και πρόσθεσε τα αρχεία του φακέλου αυτού.
2. Στο Render επίλεξε **New → Blueprint** και σύνδεσε το αποθετήριο.
3. Το Render θα διαβάσει το `render.yaml` και θα δημοσιεύσει τα στατικά αρχεία σε δημόσια διεύθυνση HTTPS.
4. Κάθε νέα αποστολή αλλαγών στο GitHub μπορεί να ενεργοποιεί νέα ανάπτυξη.

Μην ανεβάζεις μυστικά, κλειδιά, προσωπικά στοιχεία ή πραγματικά οικονομικά δεδομένα. Για εναλλακτική χωρίς σύνδεση GitHub, μπορείς να φιλοξενήσεις τα στατικά αρχεία σε άλλη υπηρεσία, αλλά δεν απαιτείται δημόσιο αποθετήριο.

## Ενδεικτικές λειτουργίες

- Ξεχωριστοί χώροι επενδυτή και επιχείρησης.
- Φιλτράρισμα έργων ανά ακίνητα/τουρισμό, πράσινη ενέργεια/γεωργία, τοπικό εμπόριο/καινοτομία και τεχνολογία.
- Ενδεικτικές αποδόσεις χρηματοδότησης και μη επαληθευμένοι στόχοι αντίκτυπου.
- Ενδεικτική προμήθεια 2% επί του κεφαλαίου για κάθε πλευρά δανείου: ο επενδυτής την καταβάλλει επιπλέον της συνεισφοράς και αφαιρείται από το ποσό που λαμβάνει η επιχείρηση. Οι χρεώσεις φαίνονται στις εκτιμήσεις και στα αρχεία δραστηριότητας, αλλά δεν εισπράττονται. Δεν εφαρμόζεται προμήθεια στις δοκιμαστικές συμμετοχές μετοχικού κεφαλαίου.
- Κανόνες αυτόματης επένδυσης που αποθηκεύονται μόνο στο πρόγραμμα περιήγησης και χειροκίνητη προσομοίωση αντιστοίχισης. Δεν γίνεται αυτόματη ή πραγματική μεταφορά χρημάτων.
- Μερική κάλυψη αιτήματος από πολλούς επενδυτές, δοκιμαστικές αντιπροσφορές και προσομοιωμένη μεταπώληση θέσης.
- Αίτημα επιχείρησης με δηλωμένα περιουσιακά στοιχεία τουλάχιστον 60% του ποσού (π.χ. €30.000 για αίτημα €50.000).
- Προσχέδιο CSV δραστηριότητας και ελληνικό FAQ.

## Όρια πρωτοτύπου και νομικές επισημάνσεις

Δεν υπάρχουν λογαριασμοί χρηστών, backend, πραγματικά χρήματα, πραγματική είσπραξη προμηθειών, πληρωμές, συμβάσεις, μετοχές, έλεγχος ταυτότητας/περιουσιακών στοιχείων, ζωντανές προσφορές, φορολογική υποβολή ή εξυπηρέτηση πελατών. Η προμήθεια 2% είναι μόνο ενδεικτικός υπολογισμός για δάνεια και όχι οριστική ή νομικά επικυρωμένη τιμολόγηση. Μη χρησιμοποιείς αληθινά ή ευαίσθητα οικονομικά στοιχεία.

Τα ονόματα, οι εικόνες, οι δραστηριότητες χρηματοδότησης, οι αποδόσεις, οι βαθμολογίες κινδύνου, οι στόχοι αντίκτυπου και τα περιουσιακά στοιχεία είναι ενδεικτικά ή συνθετικά και μη επαληθευμένα. Η βαθμολόγηση κινδύνου είναι ντετερμινιστικό παράδειγμα, **όχι τεχνητή νοημοσύνη**, αξιολόγηση πιστοληπτικής ικανότητας ή πρόβλεψη αθέτησης. Η δηλωμένη περιουσία δεν είναι επαληθευμένη ούτε εξασφάλιση. Το όριο 60% είναι κανόνας του πρωτοτύπου, όχι νομικό πρότυπο ή εγγύηση ανάκτησης. Καμία απόδοση, όπως 7–9%, δεν είναι εγγυημένη.

Η αγορά μεταπώλησης και η αυτόματη επένδυση είναι προσομοιώσεις: δεν μεταφέρεται απαίτηση, σύμβαση ή χρήμα. Οι επενδύσεις μπορεί να είναι μη ρευστές ή να οδηγήσουν σε απώλεια κεφαλαίου. Δεν υπάρχει διασύνδεση Open Banking, αυτόματη επαλήθευση, υπόσχεση έγκρισης ή εγγυημένο χρονοδιάγραμμα χρηματοδότησης.

Η εφαρμογή δεν υπολογίζει χαρτόσημο, ψηφιακό τέλος συναλλαγής ή άλλους φόρους και δεν παράγει έγγραφο έτοιμο για Taxisnet. Το CSV είναι προσχέδιο για λογιστικό έλεγχο, όχι φορολογική δήλωση.

Η εφαρμογή δεν είναι αδειοδοτημένη χρηματοοικονομική υπηρεσία. Η εφαρμογή του ευρωπαϊκού κανονισμού ECSPR εξαρτάται από την ακριβή υπηρεσία και το επιχειρηματικό μοντέλο· δεν αποτελεί γενική άδεια για κάθε μορφή δανεισμού. Πριν από πραγματική λειτουργία απαιτείται εξειδικευμένη συμβουλή για αδειοδότηση, διασυνοριακή παροχή, AML/KYC, προστασία επενδυτών, πληρωμές και φορολογία στην Ελλάδα και στην ΕΕ. Το παρόν δεν αποτελεί νομική συμβουλή.

- [Κανονισμός (ΕΕ) 2020/1503 (ECSPR)](https://eur-lex.europa.eu/eli/reg/2020/1503/oj)
- [Ερωτήσεις και απαντήσεις της ESMA για τη χρηματοδότηση μέσω συμμετοχών](https://www.esma.europa.eu/press-news/esma-news/esma-publishes-questions-and-answers-crowdfunding)
- [Επιτροπή Κεφαλαιαγοράς](https://www.hcmc.gr/)
- [Τράπεζα της Ελλάδος](https://www.bankofgreece.gr/)

## Γιατί δεν είναι ακόμη δημόσιο το backend

Το `server.py` απορρίπτει σκόπιμα κάθε εκκίνηση εκτός loopback διεύθυνσης. Δεν υπάρχουν πιστοποίηση χρηστών, δικαιώματα ανά λογαριασμό, κρυπτογράφηση μεταφοράς, διαχείριση συγκατάθεσης ή διαδικασίες προστασίας/διαγραφής προσωπικών δεδομένων. Μην προωθήσεις θύρα και μην το αναπτύξεις δημόσια.

Πριν ενεργοποιηθεί κοινόχρηστο backend στο διαδίκτυο, απαιτούνται ταυτοποίηση χρηστών και ρόλων, έλεγχος πρόσβασης σε κάθε αίτημα/προσφορά/συνεισφορά, προστασία από CSRF και κατάχρηση, HTTPS, ασφαλής φιλοξενία και αντίγραφα ασφαλείας, πολιτικές διατήρησης και διαγραφής, καταγραφή συμβάντων και νομικός/κανονιστικός έλεγχος. Το δημόσιο demo Render παραμένει μόνο για προβολή μέχρι να ολοκληρωθούν αυτά.
